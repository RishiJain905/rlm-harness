# rlmh for one platform

This package holds the compiled `rlmh` binary for one platform, byte for byte the asset on the GitHub release of the same version, plus [uv](https://github.com/astral-sh/uv) 0.13.6 (MIT or Apache-2.0, © Astral Software Inc; see `uv-LICENSE-MIT`), which `rlmh` uses on first run to fetch Python 3.12.

Don't install it directly. Install [`rlmh`](https://www.npmjs.com/package/rlmh), which picks this package for your platform.
